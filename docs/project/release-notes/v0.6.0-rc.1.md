# Mercator v0.6.0-rc.1

The first candidate for v0.6.0. It is 473 commits over v0.5.4 and lands the whole
capacity broker migration that had been sitting in an unmerged stack: the
deterministic Lab, the capacity and execution split, placement on enrolled nodes,
image and Artifact locality, per-candidate prediction with service classes, the
provider bootstrap path, and the security and durability boundaries.

Read the upgrade section before installing this anywhere. Three configuration
changes stop startup rather than degrading quietly, which is deliberate.

## Upgrading breaks without these

**`MERCATOR_SECRET_KEY` is now required.** `serve` refuses to start without it.
It was previously optional, and the three features that derive from it, stored
credential sealing, workload report tokens, and node identity signing, each
answered an absent key by disabling themselves. A deployment running without one
was running with three security features silently off. It must be at least 32
decoded bytes, hex or base64. Nothing generates it for you, and rotating it needs
`mercator rekey`.

**A non-loopback listener now requires TLS material.** A `MERCATOR_ADDR` that is
not loopback, with no certificate configured, refuses to start rather than
serving plaintext. A certificate that is configured but unreadable also stops the
process, before storage is opened. There is no path from broken security material
to a served port. Terminating TLS at a reverse proxy is still supported; see
`docs/production/install-configuration.md`.

**Administrative surfaces moved to their own listener.** Workspace create and
archive, node invitation, and sink deliver and replay answer only on
`MERCATOR_ADMIN_ADDR`, and answer 404 on the public listener before
authentication so a probe cannot tell an administrative route from a misspelled
one. `MERCATOR_ADMIN_ADDR` is required whenever the deployment is reachable
beyond its own host.

`MERCATOR_PUBLIC_URL` is now validated. A malformed value previously read as "this
deployment announces nothing" and silently disabled the public-exposure check.

## What is new

**Mercator Lab.** A deterministic executable specification. One Blueprint becomes
a reproducible control-plane run, a live console, and a replayable `.mlab` bundle,
running real placement, orchestration, reconciliation, SQLite, HTTP, SSE and
console code while simulating the provider, node, registry, Artifact store,
callback and clock boundaries. `mercator lab serve --play 1s` drives a Blueprint
to completion and opens the console so it can be watched. A paced drive issues the
same commands as the headless run and exports a byte-identical bundle.

**Capacity and execution are separate contracts.** `internal/capability` owns
`CapacityProvider`, `NodeRuntime` and `EphemeralExecutor`, and a connection's lane
is derived from the contracts it implements rather than asserted. A one-shot
execution can no longer be represented as a reusable Rental.

**Placement on enrolled nodes, with locality that is measured rather than
assumed.** Image and Artifact locality reach the score as what a host was found
holding and what it still owes, with "unknown" kept distinct from "cold". A Rental
is a domain aggregate with generations, and a generation ending retires its node.

**Prediction per candidate and service classes.** Every candidate carries staged
estimates with their confidence and source, and the Booking Decision records what
was known when the placement was taken.

**The node agent ships in the release archives.** Every archive now carries
`mercator-node` beside `mercator`, built for that archive's platform. It is the
agent both paths need: a machine an operator enrols by hand runs it from the
environment, and a machine a provider rents fetches the same binary through the
bootstrap. Hosting it for a rented machine to fetch is still the operator's job,
because that URL is inside their network.

**Security and durability.** TLS in-process, workspace-scoped RBAC enforced in
middleware with no route shape changed, provider credentials encrypted at rest
with `mercator rekey` for master-key rotation, private administrative and Lab
endpoints, and `mercator backup` as an online copy proven by restore. Crash
recovery is asserted by killing real processes mid-write.

**A Locality view in the console.** What each Run needed and what the machine it
landed on already had, read from the selected candidate of its Booking Decision.

## What this candidate does not do

Stated plainly because the headline of this release could be read as more than it
is.

**No machine has ever been rented.** The Shadeform capacity provider is proven
against its package's httptest fake, the shared conformance suite, and the Lab. It
has never run against the live API. The capacity provider should be treated as
experimental (#235).

**No production Run can reach a rented machine.** A capacity connection publishes
no placement candidate (#200), and a launch is still addressed through the
selected offer's native ref rather than the machine a provisioning built (#207).

**Nothing ends the lease of an idle machine** (#206). A rented, bootstrapped,
enrolled machine bills until an operator destroys it out of band. A provision the
provider classified as fatal is retried for ever (#236).

`docs/production/known-limitations.md` is the complete list and is current.
