# Mercator v0.6.1

This is the transport bridge for the workspace removal rollout. Mercator's
domain and SQLite state remain deployment-global exactly as in v0.6.0, while
the HTTP edge temporarily accepts the retired selector positions used by
workspace-client-v1 and returns the latest placement decision under both the
old singular key and the append-only decision chain.

Workloads already running when the broker migrates can finish: their
workspace-bound report tokens are translated at the HTTP edge and are still
bound to the exact legacy workspace/run pair. `/health/ready` now declares the
broker's build revision, storage/API epochs, supported client epochs, and
compatibility features so deploy tooling can refuse an unsafe downgrade.

The bridge logs its use at a bounded power-of-two cadence. It is intentionally
removed in the next breaking release after every live and rollback-eligible
application speaks `single-scope-client-v2`.
